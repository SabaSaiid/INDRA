# INDRA AI/ML inference contract

`backend/app/ml/contracts.py` defines `ReportInput`, component predictions, and `UnifiedMLResult`. The existing pure `app.ml.orchestration.analyze_report` remains available; Phase 26's `app.ml.inference.frozen_engine` explicitly authorizes the six frozen local artifacts. The backend-owned `app.services.ml_adapter` supplies stored report/candidate/station values and persists the result. The ML package owns no database, Kafka, Redis, HTTP, URL fetching, authentication, or media retrieval.

`UnifiedMLResult` contains `text_prediction`, `duplicate_prediction`, `event_prediction`, `credibility_prediction`, `image_prediction`, and `anomaly_prediction`, plus model/feature versions, warnings, and errors. `PredictionStatus` values are `AVAILABLE`, `NOT_RUN`, `NOT_APPLICABLE`, `OFFLINE`, `ERROR`, `NOT_IMPLEMENTED`, `INSUFFICIENT_DATA`, and `HEURISTIC_ONLY`. Each component failure is captured as a typed `ERROR`, not converted to a negative or zero score.

In the Phase 26 frozen path, missing already-loaded image bytes yield `NOT_RUN` with `MISSING_INPUT`/`IMAGE_NOT_SUPPLIED`; absent or insufficient 24-reading station history yields `NOT_RUN` with `MISSING_INPUT`. The older default component interfaces retain their existing `NOT_APPLICABLE`/`INSUFFICIENT_DATA` behavior. Neither path fabricates a zero score. The anomaly development score is labeled `SYNTHETIC_DEVELOPMENT_MODEL_SCORE`, not a field probability. Duplicate status is not misleadingness, anomaly evidence is not falsity, and heuristic event evidence is not a calibrated probability.

Event grouping is deterministic and preserves spatial, temporal, type, and complete-link constraints. One report remains a `CANDIDATE`; `CONFIRMED` requires explicit human confirmation. The backend must not manufacture image bytes, history windows, labels, probabilities, or source independence. Phase 26 stores each `UnifiedMLResult` at `raw_reports.analysis.ml` and advisory multi-report grouping at `verified_events.verification_receipt.ml_event_grouping`. Neither output overrides the legacy fusion score or human decision. A media URL alone is not image input; only caller-supplied bytes are processed.
